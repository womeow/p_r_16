# Матрица ролей

Целевые роли руководства: `operator_a` / `operator_b` и `technician_a`.
Источник: `data/service_spec.md` (SPEC-1.0), `data/operator_observations.md` (интерфейс 1.5.0).

| Действие | operator_a / operator_b | technician_a | В руководстве? |
|---|---|---|---|
| Создать заявку | Да | Нет | Да (сц. 1–3) |
| Читать собственные заявки | Да | Нет | Да |
| Редактировать собственные открытые заявки | Да | Нет | Косвенно (валидация) |
| Читать назначенные заявки | Нет | Да | Да (сц. 4) |
| Перевести `open` → `in_progress` | Нет | Да | Да (сц. 4) |
| Перевести `in_progress` → `resolved` (нужен непустой комментарий) | Нет | Да | Да (сц. 4) |
| Удалить заявку | Нет | Нет (запрещено) | Указано как отсутствующее |
| Назначить исполнителя | Нет | Нет | Нет — вне руководства (менеджер/поддержка) |
| Читать все заявки | Нет | Нет | Нет |
| Доступ неавторизованного | Запрещён | Запрещён | Да (сц. 5, отказ доступа) |

## Ограничения (из спецификации)

- title: 1–120 кодовых точек после trim; body: 1–2000 кодовых точек после trim.
- Вложения: 0–3 файла PDF/PNG, каждый ≤ 5 000 000 байт, пустой файл не принимается; проверяется фактический тип содержимого.
- При отказе валидации введённый текст остаётся в форме.
- Переход в `resolved` требует непустого комментария исполнителя.
- Доступ ограничивается сервером; отсутствие кнопки не является проверкой полномочий.
- Повтор запроса с тем же `idempotency_key` и тем же содержимым не создаёт дубль.

## Словарь терминов (5)

| Термин | Определение, помогающее действию |
|---|---|
| **Заявка** | Запись с темой, описанием, статусом и вложениями. Создаётся кнопкой «Отправить» на экране «Новая заявка»; открывается из списка. |
| **Номер** | Идентификатор конкретной записи вида `LAB-104`. Используется для поиска и повторного открытия; **не заменяется** номером кабинета или иным числом. |
| **Статус** | Состояние заявки: `open` (открыта), `in_progress` (в работе), `resolved` (выполнена). Показывается в списке и карточке. |
| **Вложение** | Файл PDF или PNG, приложенный к заявке. Допускается от 0 до 3 файлов, каждый не более 5 000 000 байт; пустой файл не принимается. |
| **Исполнитель** | Пользователь, которому назначена заявка (например, `technician_a`). Видит только назначенные ему заявки в фильтре «Назначенные». |
